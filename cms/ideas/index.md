Arguments I'm testing. Some will turn out wrong.

| Idea | Why it matters |
| :--- | :--- |
| Africa should not merely consume AI. It should build with it. | Local constraints (infrastructure, payments, language, trust) call for different architectures, and solving them can produce systems that are competitive anywhere. |
| Cheap intelligence creates new African business models. | When expertise and coordination cost less, problems that were never worth solving become worth solving. |
| AI consulting should be measured by outcomes, not presentations. | The unit of value is an improved result, not a model or a strategy deck. |
| Agentic systems are a new organizational execution layer. | Agents can take on knowledge work that used to need headcount, while humans stay responsible for consequential decisions. |
| Maximum useful intelligence per unit of cost, time, and risk. | Route cheap work to cheap models and hard work to strong ones; keep private data in trusted places. |
